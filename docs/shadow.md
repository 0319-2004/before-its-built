# 日影（冬至・地上1.5m）

計画建物の直方体が落とす影を、**自前で計算**して地上1.5mの平面に描く。
時刻スライダー（冬至8–16時）で動かす。方針は dev-policy §10、実装は `web/src/shadow.ts`。

```sh
cd web && npm run dev
# http://localhost:5173/?stage=1&shadow=1          届出の青棟に日影
# http://localhost:5173/?stage=2&shadow=1&time=14  ＋解体、初期14時
# http://localhost:5173/?mode=sample&shadow=1       サンプルの立てた建物に日影
```

**これは法令上の日影規制の判定ではない。** 冬至・地上1.5m・建物は直方体で近似した
目安で、スライダーの下に必ずその断りを出す（dev-policy §10）。

## なぜ自前計算なのか

NAVARA は `shadow: true`（既に有効・CSM）で**リアルタイムの影**を描けて、
`atmosphere.date` を冬至にし `setSolarTime` で時刻を与えればシーンの光も冬至になる。
しかし **CSMの影は3Dジオメトリの上にしか落ちない**。背景の地図（OSMラスタ）は
照明を受けないので、**更地の計画地には影が1枚も映らない**（dev-policy §9 の「夜に真っ黒」と
同じ理屈）。計画地はたいてい更地なので、これでは意味がない。

そこで §10 の「冬至・直方体近似・**地上1.5mで計算**」に従い、影の範囲をコードで出して
平面ポリゴンで描く。スライダーはシーンの光（CSM）も同じ冬至時刻に合わせるので、
既存のPLATEAU建物には本物の影も付く（「両方」）。§14 の「NAVARAで日影が出せるか」は
**出せる**（CSM＋自前の1.5m平面）で決着。

## 計算

太陽の方位角APIは無いので、太陽位置は**自前で解析計算**する（NAVARAのECEF規約に
依存しない）。冬至の赤緯 δ=−23.44°、真太陽時 h から時角 H=(h−12)·15°：

```
sin(高度) = sinφ·sinδ + cosφ·cosδ·cosH
方位A(北0・東90) = atan2(sinH, cosH·sinφ − tanδ·cosφ) + 180°
```

影は、天面（footprint を高さ h にコピー）を**1.5m平面（z=base_z+1.5）へ太陽と反対向きに
投影**し、footprint と投影した天面の**凸包**を取る（直方体の影）：

```
水平オフセット = (h − 1.5) / tan(高度)   向き = 反太陽 (−sinA, −cosA)[ENU]
```

メートル→経緯度は `stage1.ts` と同じ係数。各頂点に z=base_z+1.5 を持たせ、
`perPositionHeight: true` で平らに描く（押し出し無し）。棟ごとに底面高が違っても
1レイヤにまとめられる。色は青/オレンジを避けた暗い半透明のスレート（§10 と混ぜない）。

- 夜（高度≤0）は描かない。低い太陽で伸びすぎる影は **500mで頭打ち**。
- h≤1.5m は footprint のみ。
- 全棟を1つの source/layer にまとめ、スライダー変更時はこの1レイヤだけ rAF で差し替える。

## 撮って確かめたこと（中目黒・冬至）

真上（`pitch=-80`, `heading=0`＝北が上）から No.3（h=9.9m）の影の向きを撮り比べた。
数値検算と画面が一致：

| 真太陽時 | 太陽高度 | 太陽の方位 | 影の向き | 影長/高さ |
|---|---|---|---|---|
| 8:00 | 8.1° | 126.6°（南東） | **北西**（画面左上） | 7.0 |
| 12:00 | 30.9° | 180.0°（真南） | **北**（短い、足元） | 1.67 |
| 16:00 | 8.1° | 233.4°（南西） | **北東**（画面右上） | 7.0 |

朝=北西・夕=北東で**符号は正しい**（符号が逆なら朝が南東になる）。正午は影が短く
（オフセット≈14m＝建物とほぼ同じ）足元に収まる。朝夕の影が高さの7倍に伸びるのも
冬至らしい。ビルド（`npm run build && npm run preview`）でも stage1・サンプルとも
同じに描け、console.error は favicon の1件だけ。

## 「あなたの家」の日影時間（タップ）

地図をタップすると、その地点（地上1.5m）が冬至の8–16時に計画建物のどれかの影へ
入る**時間帯と合計**を出す（10分刻み）。マーカー（シアンの丸）を置き、下のパネルに
「合計 N時間M分／時間帯 10:10–12:40, …」を出す。影に入らなければその旨を出す。
段階1/2 とサンプルモードの両方で使える（日影と同じ `addShadowStudy` に載っている）。
断り（法令の判定ではない目安）はここでも常時出る。

**タップ点の緯度経度は、楕円体ではなく地面の高さの水平面に当てて出す。**
NAVARA の `click` イベントの `map` は楕円体面（標高0）のECEFで、目黒区の地面は
楕円体高で約46〜67mあるため、斜め視点だと楕円体に当てた点は地面と大きくずれる
（pitch −22°で約138m）。そこでカメラ位置からタップ点へのレイを、代表点の地面高に
置いた水平面（`getPlaneFromPointNormal` / `getRayPlaneIntersection`）に当て直し、
`vector3ToGeodetic` で緯度経度にする。すべて NAVARA の同じECEF内で完結する。

撮って確かめた（真上と斜めで同じ建物をクリック）:

| 視点 | クリック位置 | 出た緯度経度の建物中心からの距離 |
|---|---|---|
| 真上（pitch −90） | 建物中心 | 0.0m |
| 斜め（pitch −22） | 建物中心 | **0.7m**（楕円体のままなら約138mずれる） |

日影時間も符号が合っている：建物の真南の点は0分（冬至の影は北へ出る）、
建物の北16mの点は7時間（8:30–15:30。朝夕の低い太陽では影が北西・北東へ逃げて外れる）。

## 公開インターフェース（`web/src/shadow.ts`）

- `sunAltAz(hours, latDeg)` → `{altDeg, azDeg}`（冬至固定）
- `shadowRing(volume, hours, latDeg)` → 影リング `[lng,lat,z][]` または null
- `shadowHoursAt(lng, lat, volumes, latDeg)` → `{intervals, totalMin}`（「あなたの家」）
- `addShadowStudy(view, volumes, {lng, initialHour})` → 影レイヤ＋スライダー＋タップを作り、
  `atmosphere.date` を冬至に固定、スライダーで `setSolarTime` と再描画、タップで日影時間を出す。
  戻り値 `{setHour, destroy}`。`volumes` は `{footprint, base_z_m, display_height_m}[]`。

段階1/2 は `main.ts` が `addStage1` の返す `volumes`（描いた棟の実寸）を渡す。
サンプルモードは立てた1棟を渡し、件を切り替えるときに `destroy()` で片付ける。

## まだやっていない

- 日影図の**等時間線**（2h/3h/4h… と影がかかる累積時間の等値線）。今回は瞬間の影＋
  スライダーまで。等値線はポリゴンの和集合と等値線抽出が要るので別途。
- 地面の起伏は見ていない（1.5m平面は各棟の底面基準の水平面）。
- 影を受ける側（隣家）の窓の高さなどは見ていない（あくまで地上1.5mの目安）。
