# Before It's Built

Snap a photo of a Japanese construction notice board, and an agent built on SAM 3.1 + Muse Spark reads it, verifies it against land-registry and open data, and raises the future building in 3D on PLATEAU.

Built from scratch during the Meta Global AI Developer Hackathon (Oct 27 – Nov 4, 2026).

## Meta models used
- SAM 3.1
- Muse Spark 1.3
